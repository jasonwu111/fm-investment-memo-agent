FINAL STANDARD USER PROMPT TEMPLATE

Please prepare the "Fund Terms Summary" section for an LP investment due diligence memo.

Target Fund: [insert exact fund name]
GP / Firm: [insert firm name if known; otherwise infer from the sources]
Relevant Investor Class / Vehicle: [insert class, feeder, or vehicle if applicable; otherwise determine from the sources]
Source Materials: Use the attached knowledge base / shared folder.
Output Format: Word document if available.

Please begin with the Legal Documents folder and identify the most current and controlling documents for the target fund, including any LPA, PPM, term sheet, amendments, or supplements.

Extract the fund-specific terms and map them into the standard two-column "Fund Terms Summary" table defined in your instructions. Make sure every term applies to this exact fund and relevant investor class. Do not use terms from predecessor funds, parallel vehicles, other strategies, or unrelated investor classes.

Cross-check all material percentages, dates, thresholds, calculation bases, extension rights, approval requirements, exceptions, and class-specific economics. Check definitions, schedules, appendices, amendments, and later sections of the documents before finalizing each material term.

If a term is relevant but not disclosed, label it "Not disclosed in the reviewed materials" rather than estimating it. Use "None" only if a source affirmatively states that none applies.

Please provide:

1. A final memo-ready Fund Terms Summary table.
2. A separate short review note listing unresolved source conflicts, missing material terms, or provisions requiring manual confirmation.

Do not place the review note inside the final memo table.
